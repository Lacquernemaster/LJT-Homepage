# Junteng Liu's Homepage

This repository contains the personal academic website of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template.

## Site structure

- `_pages/about.md` — the home page (personal details, academic background, research experience, publications, skills, and contact information)
- `_pages/publications.html` — the publications list
- `_publications/` — individual publication entries
- `_config.yml` — site-wide configuration
- `_data/navigation.yml` — header navigation
